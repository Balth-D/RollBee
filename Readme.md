RollBee aims to bring a dumb roller garage door controller to the smart home world!

RollBee turns a traditional roller garage door into a smart Zigbee-enabled smart device using ESP32-H2, custom PCB, and open-source integration with Zigbee2MQTT and OpenHAB. This project demonstrates how IoT can modernize existing systems without waste. It leverages Espressif’s ESP32-H2 and Zigbee SDK to create a practical IoT solution, showcasing innovation, sustainability, and open-source collaboration.

Key features:
- Zigbee connectivity via ESP32-H2
- Custom PCB with power converter and load control
- Integration with Zigbee2MQTT and OpenHAB
- Temperature and humidity sensing

## Developement

Using the devcontainer with VSCode is the easiest. Builds for ESP32-H2 WROOM and custom PCB.

ESP-IDF v5.4.0 and ESP-Zigbee-SDK 5.4.0.

RollBee.js is the custom converter to integrate the Zigbee device with Zigbee2MQTT.
